Ridgeline Courier — a 3D valley flight game: thread 8 glowing gates down Foxglove Valley and land on the north field. Keyboard + mouse controls, throttle and turn discipline, fuel and stall, synthesised engine and wind sound, and a lit HUD with speed, altitude, heading and an artificial horizon.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. No build step, no network requests — the whole valley is built in your browser from the files under game/.
